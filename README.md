# IITrack
Intern Project
IITrack adalah platform manajemen proyek terpusat untuk Inkubator IT (IIT), HMIF ITB.
Platform ini dirancang untuk mempermudah pengelolaan dan pemantauan proyek dalam satu tempat, mulai dari pencatatan informasi proyek, pembagian penanggung jawab, pemantauan progres, hingga pengelolaan dokumentasi.
Dengan IITrack, proses pengelolaan proyek yang sebelumnya tersebar di berbagai dokumen dan platform dapat dilakukan secara lebih terstruktur, transparan, dan mudah dipantau.
